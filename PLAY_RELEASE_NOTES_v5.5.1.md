# BM Voice Studio 5.5.1

## Қазақша

- Дауыс клондау «Үлгі → Растау → Дайын» қадамдарына бөлініп, интерфейс жаңартылды.
- Микрофон рұқсаты автоматты сұралады; қажет болса қолданба баптауына өтуге болады.
- Модельді жүктеу, жалғастыру, орнату және SHA-256 тексеруі тұрақтандырылды.
- Офлайн speaker/ASR модельдерін ашқанда қолданбаны жапқан native crash түзетілді.
- Жарнама клондау терезесін жаппайды, экран portrait режимінде қалады.
- Қолданба Android recent apps тізімінде сақталады.

## Русский

- Обновлён интерфейс клонирования: «Образец → Проверка → Готово».
- Разрешение на микрофон запрашивается автоматически; добавлен переход в настройки.
- Стабилизированы загрузка, продолжение, установка и SHA-256-проверка моделей.
- Исправлен native-сбой при открытии офлайн-моделей speaker/ASR.
- Реклама не перекрывает окно клонирования, экран остаётся в портретном режиме.
- Приложение сохраняется в списке недавних Android.

## English

- Redesigned voice cloning into Sample → Verify → Ready steps.
- Microphone permission is requested automatically, with an app-settings shortcut.
- Stabilized model download, resume, install, and SHA-256 verification.
- Fixed a native crash while opening offline speaker/ASR models.
- Ads no longer cover the cloning dialog and portrait mode remains locked.
- The app stays in Android recents.
