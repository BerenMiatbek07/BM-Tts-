# BM Voice Studio 5.5.2

## Қазақша

- Дауыс растау моделі 2-қадамға өткенде автоматты жүктеледі.
- Үзіліп қалған 320 МБ жүктеу сақталған жерінен жалғасады.
- GitHub желіде ашылмаса, ресми Hugging Face көзі автоматты қолданылады.
- Желі, бос жад, зақымдалған файл және орнату қателері енді бөлек әрі түсінікті көрсетіледі.
- Жартылай орнатылған модель қайтадан толық жүктелмейді.
- APK/AAB ішіне ескі кэш-кодтың кіріп кетуіне жол бермейтін build тексеруі қосылды.

## Русский

- Модель проверки голоса автоматически загружается при переходе к шагу 2.
- Прерванная загрузка 320 МБ продолжается с сохранённого места.
- Если GitHub недоступен в сети, автоматически используется официальный источник Hugging Face.
- Ошибки сети, памяти, повреждённого файла и установки теперь различаются.
- Уже установленные части модели не скачиваются повторно.
- Добавлена проверка, исключающая старый кэшированный код из APK/AAB.

## English

- The voice verification model now downloads automatically on step 2.
- Interrupted 320 MB downloads resume from saved progress.
- An official Hugging Face source is used automatically when GitHub assets are unavailable.
- Network, storage, corrupted-file, and installation errors now have distinct messages.
- Installed model components are not downloaded again.
- Build verification now prevents stale cached code from entering APK/AAB files.
