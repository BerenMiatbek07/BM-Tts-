# Google Play release notes — BM Text to Voice v5.2.6

## Қазақша — kk-KZ

BM Text to Voice v5.2.6

- Исәке және Рая офлайн дауыстары түзетілді.
- Android-пен үйлеспейтін FP16 модельдері жасырылды.
- Бұрынғы FP16 дауыс таңдауы үйлесімді модельге автоматты ауысады.
- Дауыс жүктеу, алдын ала тыңдау және аудио сақтау тұрақтандырылды.
- API 36 және 16 КБ жад беттері қолдауы жақсартылды.

## Русский — ru-RU

BM Text to Voice v5.2.6

- Исправлена работа офлайн-голосов Исеке и Рая.
- Несовместимые с Android модели FP16 скрыты.
- Ранее выбранный голос FP16 автоматически заменяется совместимой моделью.
- Улучшена стабильность загрузки голосов, предпрослушивания и сохранения аудио.
- Улучшена поддержка API 36 и страниц памяти 16 КБ.

## English — en-US

BM Text to Voice v5.2.6

- Fixed the Iseke and Raya offline voices.
- Android-incompatible FP16 models are now hidden.
- Previously selected FP16 voices automatically migrate to compatible models.
- Improved voice downloads, audio previews, generation, and saving stability.
- Improved API 36 and 16 KB memory page support.
